Domain: Service operations across sectors: automotive service (the showcase), equipment maintenance, facilities management, utilities and energy, healthcare equipment and aviation maintenance.

Technical deployment: runs on one NVIDIA Brev L40S (48 GB) with three self-hosted NIMs; speech-to-text through NVIDIA-hosted Riva. Built and demonstrated for automotive service; the other sectors are the intended deployment area, not yet built. 		Service Operations Intelligence Agent: Job information is spread across notes, calls, messages and systems, so the challenge is moving it accurately and finding it again when it matters.

People ask again, search and re-type the same update. Resources get over-committed: crews double-booked, parts ordered twice. Critical findings get buried in notes, leading to delays, rework and safety incidents. AI answers that cannot be traced or checked make it worse. 		Nemotron Nano 8B (NIM): reads updates into structured JSON and narrates search results
NV-EmbedQA E5 (NIM): embeddings for update search and operation matching
NV-RerankQA 4B (NIM): reranks search candidates before they are cited
Riva Parakeet / Magpie: speech-to-text and text-to-speech
NeMo Guardrails: input and output rails
NeMo Curator: curation; quarantines prompt injection before indexing
NeMo Evaluator: seven benchmarks, run over run
NeMo Relay: per-stage traces
NeMo Agent Toolkit: the agent as a workflow over 11 typed tools
NeMo Switchyard: local or hosted model routing (off by default)
NVIDIA DCGM: GPU telemetry
NVIDIA Brev: L40S compute
